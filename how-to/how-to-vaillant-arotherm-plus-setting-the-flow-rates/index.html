How to – Vaillant Arotherm Plus Setting the Flow Rates

Step-by-step guide to viewing and adjusting flow rates on Vaillant Arotherm Plus heat pumps using the WWZ Al MB2 or MEH 97/uniTOWER display.

Flow rates can be viewed by using the WWZ Al MB2 or MEH 97/uniTOWER display.

Viewing Flow Rates

Access by pressing the top 2 buttons at the same time (possibly twice as usually the first press will light the display up)

  • Use the + button to scroll down the menu to installer level, – press top right-hand button to select
  • The access code is 17, use + button to adjust, – press top right-hand button to select
  • Use the + button to scroll down to Test menu, – press top right-hand button to select
  • Use the + button to scroll down to Sensor/Actuator test, – press top right-hand button to select
  • Press + button 10 times to view Building circuit: Flow rate

Adjusting Flow Rates

If the flow rate needs to be adjusted, then this can be accessed by following the below:

Access by pressing the top 2 buttons at the same time (possibly twice as usually the first press will light the display up)

  • Use the + button to scroll down the menu to installer level, – press top right-hand button to select
  • The access code is 17, use + button to adjust, – press top right-hand button to select
  • Use the + button to scroll down to Configuration, – press top right-hand button to select
  • Press the + button 7 times to Max. remaining feed head, – press top right-hand button to adjust

Note: You may need to adjust max. remaining feed head and recheck the flow rate in test menu – sensor/actuator test – building circuit flow rate. Max remaining feed head parameter adjusts the pump in both heating and domestic hot water modes.
