How to adjust the Power level on Vaillant Ecotec – Post 2012 Models

Newer ecoTECs with four rectangle buttons and no dials. Set heating partial load to the kW the system needs, instead of leaving it on Auto.

Newer Ecotecs with 4 rectangle buttons and no dials

Work out the output first

Before you change heating partial load, work out the heat output of the radiators and circuits, then add them up to a kW total. That kW is what you set on the boiler.

Use the Heating System Output Calculator to get radiator watts and the total system output in kW.

Written instructions

  1. Press the top 2 buttons below the screen to access the ‘menu’.
  2. Scroll to ‘Installer Level’ using ‘+’ and ‘-’ buttons
  3. Enter code 17 and press ‘OK’
  4. Scroll to ‘Appliance config’ using ‘+’ and ‘-’ buttons and press ‘Select’
  5. Scroll to ‘Heating partial load’ using ‘+’ and ‘-’ buttons and press ‘Select’
  6. Using plus and minus button, adjust to required kW and press ‘OK’

The default setting is Auto. According to experts, that is not the recommended setting for most UK installations.
