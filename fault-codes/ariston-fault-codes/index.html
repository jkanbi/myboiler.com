Ariston Fault Codes

Display codes for Clas, E-Combi, E-System and related Ariston ranges.

Back to Advice

The first digit is the circuit: 1xx heating, 2xx DHW / solar, 3xx internal PCB, 4xx external PCB / room sensors, 5xx ignition, 6xx air / flue, 7xx multi-zone. A P in the code (1P1, 5P3) is a warning, not a lockout. Some numbers only apply to a named range — check the model column before you order parts.

Gas work stays with a Gas Safe registered engineer. This table is the display meaning, not a substitute for the Ariston handbook.
