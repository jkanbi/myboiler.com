Vaillant F49 Fault Code

eBUS fault

Fault codes / Vaillant

Gas Safe: Gas work, flue work, and PCB replacement on a gas boiler must be carried out by a Gas Safe registered engineer. Homeowners can check obvious items such as heating pressure, condensate overflow, and whether a control is unplugged — then call an engineer.

Always confirm the part number against the boiler GC number and the installation manual before ordering.

Overview

F.49 is a problem on the eBUS: short, overload, or two supplies with opposite polarity. Controls, VR33 OpenTherm modules, extra room units, and damaged two-core cable are the usual extras on the bus.

Vaillant meaning: eBUS fault

Possible causes

  • eBUS cores shorted together or to earth
  • Too many devices / a failed control drawing the bus down
  • Two power sources on the bus with reversed polarity
  • Water in an outdoor sensor or control backplate

Possible solutions

  1. Disconnect all external eBUS devices (room unit, VR66/VR33, outdoor sensor) at the boiler terminals. If F.49 clears, add them back one at a time.
  2. Check polarity of every eBUS pair. Reverse polarity on a second supply is a classic F.49.
  3. Inspect the two-core cable for staples and joints in wet locations.
  4. A failed control or VR33 can hold the bus down — unplug suspects rather than replacing the boiler PCB first.

Possible parts needed

  • eBUS two-core cable
  • Room / weather control
  • VR33 or other eBUS interface if fitted — see VR33 installation
  • Boiler PCB (only if the bus is clean with everything unplugged and the fault remains)
