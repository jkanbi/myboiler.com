How to Adjust the Flow Temperature on Vaillant Ecotec Post 2012 Models

Set the flow temperature with + and −. The factory setting is usually 75°C.

From 2012, ecoTECs have four rectangular buttons and no dials.

  1. Press the button under the radiator symbol.
  2. Set the flow temperature with + and −.
  3. Press OK.
  4. Press back once to return to the home screen.
