How to adjust the flow temperature on a Vaillant ecoTEC new type

Set the flow temperature on the screen. The factory setting is 75°C.

Controls that are lit in colour can be pressed. Change a number by tapping the top or the bottom of the scrollbar. A new number is saved only after you press the flashing control to confirm.

  1. If the status display is showing, press the control that opens the basic display.
  2. From the basic display, press the heating control. That is the control for the flow temperature.
  3. Set the flow temperature with the scrollbar.
  4. Press the flashing control to confirm.
