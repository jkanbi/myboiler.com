Vaillant Diagnostic S-Codes & D-Codes

Complete reference guide for Vaillant ecotec boiler status codes (S-codes) and diagnostic parameters (D-codes). Essential technical information for heating engineers.

For Qualified Engineers Only: This information is intended for Gas Safe registered engineers. Adjusting diagnostic parameters can affect boiler operation and efficiency. Always refer to the manufacturer's installation and servicing instructions.

About S-Codes and D-Codes

Vaillant ecotec boilers use two types of codes for diagnostics and configuration:

  • S-Codes (Status Codes): Display the current operating status of the boiler. These are read-only indicators showing what the boiler is currently doing.
  • D-Codes (Diagnostic Codes): Adjustable parameters that control various aspects of boiler operation. These can be modified by qualified engineers to optimize performance.

How to Access S-Codes and D-Codes

  1. Press the info button (i) on the boiler control panel
  2. Use the + and - buttons to scroll through codes
  3. For D-codes, press and hold the info button for approximately 5 seconds to enter adjustment mode
  4. Use + and - to change values, then press OK to confirm

Note: Some newer ecotec models may have slightly different navigation. Always consult the specific manual for your boiler model. See Vaillant Anti-Cycling Time for more configuration information.

D-Codes: Diagnostic Parameters

D-codes are adjustable parameters that allow engineers to configure and optimize boiler performance. Each D-code controls a specific function or setting.

Warning: Incorrect adjustment of D-codes can lead to inefficient operation, increased energy consumption, or boiler faults. Only adjust these parameters if you fully understand their function.

Common D-Code Adjustments

Optimizing for Efficiency

For condensing operation and maximum efficiency:

  • D.0: Set to 55-60°C for well-insulated properties with larger radiators
  • D.2: Increase to 30+ minutes to reduce cycling
  • D.71: Range rate to match actual heat loss calculation
  • D.110/D.111: Use weather compensation for optimal efficiency

Reducing Cycling

To minimize short cycling:

  • Increase D.2 (anti-cycling time) to 30-40 minutes
  • Adjust D.1 (minimum output) to match system requirements
  • Increase D.19 (burner run-on) to ensure longer burn times
  • Consider reducing D.71 if system is oversized

DHW Performance

For optimal hot water delivery:

  • D.40: Set to 60°C for legionella protection with stored hot water
  • D.41: Adjust flow rate to suit property demands (8-11 l/min typical)
  • D.47: Use Eco mode (0) to prevent pre-heat losses
  • D.72: Range rate DHW if oversized

Reading Current Values

Many D-codes also show current operating values when in read mode:

  • Flow temperature (actual)
  • Return temperature (actual)
  • DHW temperature (actual)
  • Current burner power (%)
  • Current fan speed (rpm)
  • Current pump speed (%)

Documentation: Always document any changes made to D-codes in the benchmark log. This helps future engineers understand system configuration and troubleshoot issues.

Safety and Compliance

  • Only Gas Safe registered engineers should adjust D-codes
  • Some parameters require manufacturer authorization
  • Changes may affect warranty if not properly documented
  • Always perform a full functional test after adjustments
  • Verify flue gas analysis meets Building Regulations
  • Complete benchmark commissioning sheet
