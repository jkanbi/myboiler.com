How to repair a thermostatic radiator valve (TRV) using a service tool

Introduction – In this how to page we show you how to replace a faulty / leaking TRV insert using a service tool. This can save on having to drain down the system as it works on the live system.

Video – How to Change a faulty radiator TRV valve without draining using a IMI removal tool.

In the video below, it shows how certain valves are compatible with removal tools. For this video we have used an IMI valve removal tool on a Altecnic/ Caleffi TRV.

Show below is a table showing popular TRVs and the availability of repair tools as well as compatibility with the IMI tool.

Common problems with TRVs and radiator valves

  • Leaking glands
  • Broken shafts.
  • TRV pins that have stopped moving properly or internals are not functioning properly
